P6SemiImageEditor　操作説明

P6ImageConverterの変換結果を、PC-6001系の文字画面として見ながら編集するWindowsアプリです。画面は40列×20行、1セルは8×10ドットです。文字512種類（通常256・セミグラフィック256）から1セルに1文字を選び、文字色と背景色を指定します。

起動
  1. Windowsの書き込み可能なフォルダーにZIPを展開します。
  2. 展開先の Start.cmd をダブルクリックします。Windows用 .NET Framework 4.8または4.8.1が必要です。初回はWindowsのC#コンパイラでビルドし、自己テストが通るとエディタが開きます。追加のパッケージの取得はありません。
  3. ［開く］で変換結果を選びます。エディタの画面または Start.cmd にデータファイルを1つドラッグしても開けます。
  初回ビルド後は bin\Release\P6SemiImageEditor.exe を直接起動できます。移動する場合は、同じフォルダーの font-atlas.png と P6SemiImageEditor.exe.config を一緒にコピーしてください。
  再ビルドと自己テストは Build.cmd で実行できます。自己テストでエラーが出た場合の詳細は bin\Release\self-test-error.txt に記録されます。

セルの編集
  ［セルを編集］で画像の直したい部分を左クリックします。右側の一覧で字形をクリックするか、［文字色］［背景色］を選ぶと、そのセルにすぐ反映されます。画面にフォーカスした状態では方向キーで隣のセルへ移れます。座標は左上が (0, 0) です。
  ［文字一覧］で通常文字とセミグラフィックを切り替えます。表の行はコードの上位桁、列は下位桁です。色番号と文字コードは16進表記です。［グリッド］と［表示倍率］を使うと、目や口を構成するセルを見分けやすくなります。
  フォーカスがある項目ではキーで選択できます。［文字色］は 0～F（0は透明色のコード）、［背景色］は 8～F、［文字一覧］は 0 が通常文字、1 がセミグラフィックです。文字コードの表では、例えば 8 で 80H を選び、続けて A で 8AH を選びます。80H をクリックした直後も A で 8AH を選べます。
  ［ブラシで描く］では、一覧で選んだ文字と色を左ドラッグで連続して置けます。既存のセルを右クリックし、［ブラシに採取］を選ぶと、その字形・文字色・背景色をまとめて採取できます。Ctrl+Z で元に戻し、Ctrl+Y でやり直します。1回のドラッグは1操作です。
  選択した1セルの文字と色をコピーできます。コピー元と貼り付け先のセルを右クリックし、それぞれ［コピー］と［ペースト］を選びます。セルを選択して編集メニューや Ctrl+C／Ctrl+V を使うこともできます。ペーストは Ctrl+Z で元に戻せます。
  セルをダブルクリックするか［選択セルをドットで編集］を押すと、そのセルを拡大できます。左側に希望の形を描きます（左ボタンで文字色、右ボタンで背景色）。右側に、現在のフォント512文字のうち異なるドット数が最も少ない実際の字形と、希望の形との差が出ます。［この文字を適用］で掲載中の字形を保存データに反映します。

目と肌色の編集例（標準パレット）
  ・白目に紺の瞳を入れる場合は、左側の目のセルを選び、セミグラフィックの0行2列（02H）、文字色4（紺）、背景色F（白）を指定します。右側の目は0行1列（01H）にして同じ色を指定します。両目とも下向き矢印にする場合は、2行B列（2BH）を両方に適用します。
  ・顔の黄色一色のセルを橙と白のタイリングにする場合は、［ブラシで描く］でセミグラフィックの2行5列（25H）、文字色1（橙）、背景色F（白）を選び、対象セルを塗ります。

読み込みと保存
  .frame.bin　　　1,600バイト。属性800バイトに文字コード800バイトが続きます。
  .vram.bin　　　 2,048バイト。属性は0000H、文字コードは0400Hからです。読み込んだVRAMの未使用領域も保持します。
  .chr.bin と .atr.bin　各800バイト。前者が文字コード、後者が属性です。同じ名前のペアを同じフォルダーに置き、どちらか一方を選びます。保存時は両方を書き出します。
  Ctrl+S は開いた形式を保存します。同じ名前で別形式のファイルも必要な場合は、Ctrl+Shift+S（名前を付けて保存）で形式を選んでください。変換時のプレビューとは別に、［ファイル］→［画像をPNGに書き出す］で編集後の4対3画像（640×480）を保存できます。グリッドや選択枠は書き出し画像に含まれません。

フォントとパレット
  同梱の font-atlas.png を標準フォントとして使用します。元のコンバーターと同じ名前のJSON（例として pic.frame.bin に対する pic.json）があると、開くときに変換時のパレットを復元し、フォントのSHA-256を照合します。必要なフォントは、データと同じフォルダー、続いてJSONに記録されたローカルパスから探します。
  ［表示］から256×160のフォント一覧PNG、8,192バイトのCGROM、またはコンバーター用パレットCSVを手動指定できます。画面バイナリが記録するのは文字コードと色番号です。別名で保存して独自フォントやパレットを使う場合は、次に開いたときも同じ設定を選んでください。
